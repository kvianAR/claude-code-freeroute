# Contributing

Issues and pull requests are welcome for setup instructions, launcher fixes, and tested provider configurations.

- Never include real API keys, local settings, gateway logs, or screenshots showing credentials.
- Keep example settings usable without private values.
- Explain which route you tested: OpenRouter or direct NVIDIA.
- For launcher changes, run `python3 -m py_compile start-claude` and check a clean clone setup.

Please keep provider-specific behavior clear so readers can tell which account and limits apply.
